# Security Policy

## Supported versions

No supported public release has been published yet. After the 1.0 launch, security fixes will target the latest published release.

## Reporting a vulnerability

Please report vulnerabilities privately. Do not open a public issue containing security details.

- Open the repository's **Security** tab and choose **Report a vulnerability**.
- If that option is unavailable, email [support@directorofrealms.com](mailto:support@directorofrealms.com).

Include the affected version, Foundry VTT version, reproduction steps, and expected impact. Never include API keys, access tokens, Patreon credentials, or an unredacted world export.

## Package authenticity

Install Director of Realms only from this repository through its Foundry VTT marketplace listing or official manifest URL. Published release tags and assets are immutable. Verify the SHA-256 checksums supplied with each release, and do not install packages from forks or third-party mirrors.
