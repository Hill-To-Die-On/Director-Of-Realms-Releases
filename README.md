# Director of Realms — Official Releases

This is the official public distribution repository for **Director of Realms**, a Foundry VTT v14 module.

No supported 1.0 release has been published yet. When releases begin, install only through the Foundry VTT package listing or the manifest URL published in this repository.

## Authenticity

- Official packages are published only by **Hill-To-Die-On**.
- Published releases and their tags are immutable.
- Do not install packages from forks or third-party mirrors.
- Each release will include the Foundry manifest, the module ZIP, and SHA-256 checksums.
- Development source is maintained separately; this repository is the distribution boundary and does not accept source-code contributions.
